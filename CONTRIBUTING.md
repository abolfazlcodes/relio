# Contributing to Relio

Relio is currently following its documentation-first implementation plan.

Before contributing, read:

1. [Developer onboarding](docs/development/developer-onboarding.md)
2. [Master development tracker](docs/development/MILESTONES.md)
3. [Contributing guide](docs/development/contributing.md)
4. [Coding standards](docs/development/coding-standards.md)
5. [Governance and ownership](docs/maintenance/governance.md)

Implementation changes must target the active milestone and remain within its
scope. Security vulnerabilities must follow [SECURITY.md](SECURITY.md), not a
public issue.

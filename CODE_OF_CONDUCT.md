# Code of Conduct

We want this project to be a welcoming, technically rigorous place to collaborate.

Participants are expected to:

- be respectful and assume good intent;
- focus criticism on ideas, code, and outcomes rather than people;
- explain tradeoffs clearly and welcome questions;
- avoid harassment, discrimination, personal attacks, and unwanted contact;
- respect different backgrounds, experience levels, and communication styles.

Project maintainers may remove comments, close discussions, or restrict participation when behavior violates these expectations. For conduct concerns, use the private reporting channel published in the repository metadata. Do not use public issues for sensitive reports.

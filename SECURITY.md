# Security Policy

Security issues must not be reported in public issues or discussions.

Until a dedicated private reporting address is published, contact the maintainers through the private channel listed in the repository metadata and include:

- affected version or commit;
- operating system and environment;
- concise reproduction steps or proof of concept;
- impact and any known mitigations.

The canonical security architecture is documented in
[docs/security](docs/security/README.md), including the
[threat model](docs/security/threat-model.md),
[credential storage](docs/security/credentials.md),
[secret management](docs/security/secrets.md),
[SSH security](docs/security/ssh.md),
[encryption strategy](docs/security/encryption.md),
[update security](docs/security/updates.md),
[supply-chain security](docs/security/supply-chain.md), and
[privacy principles](docs/security/privacy.md).
